# Тихая Коломна

Одностраничный демонстрационный сайт бутикового гостевого дома.

## Структура

- `index.html` — семантическая структура страницы;
- `css/style.css` — визуальная система и адаптивные стили;
- `js/main.js` — интерактивность;
- `assets/images/house` — фасад, двор и детали дома;
- `assets/images/rooms` — фотографии номеров;
- `assets/images/kolomna` — город и места рядом;
- `assets/fonts` — локальные шрифты;
- `assets/icons` — необходимые иконки.

Правила дизайна и разработки находятся в `AGENTS.md`.
