# AGENTS.md

## Project Goal

Build a polished one-page website for a boutique guest house called **«Тихая Коломна»**.

The website should feel modern, calm, warm and locally rooted in Kolomna, but it must NOT look like:
- a generic hotel template
- Booking.com
- Airbnb
- a developer portfolio
- a generic AI-generated landing page

The goal is to create a site that feels like a real boutique guest house with its own visual identity.

The experience should communicate:

- calm
- comfort
- privacy
- thoughtful design
- local atmosphere
- modern hospitality
- connection to Kolomna

The result should feel intentionally designed for this specific guest house.

---

# Core Visual Direction

The visual style should be:

- contemporary boutique hospitality
- warm but not brown-heavy
- elegant without being luxurious in a cliché way
- calm and atmospheric
- editorial rather than corporate
- locally inspired without becoming folkloric
- clean, tactile and slightly architectural

Avoid the obvious beige + dark brown + olive palette.

This project should have its own identity and should not reuse the same palette often used for coffee shops, portfolios or rustic brands.

Use a fresher palette direction such as:

- warm ivory
- chalk white
- muted dusty blue
- soft clay / faded terracotta
- desaturated burgundy as a small accent
- muted stone gray
- deep graphite
- pale warm peach or muted rose where appropriate

Do not use all of these equally.

Choose a restrained system with:
- one dominant light base
- one dark text / contrast color
- one main accent
- one secondary subtle accent

The palette should feel calm, architectural and slightly editorial.

---

# Most Important Rule

Before implementing any major section, ask:

> "Could this exact section exist unchanged on a SaaS website, developer portfolio, generic hotel template, Airbnb clone or AI-generated landing page?"

If yes, redesign it.

The site must feel specific to:
- a boutique guest house
- Kolomna
- short stays
- quiet atmosphere
- local architecture
- travel

---

# Avoid Generic Hotel Design

Strictly avoid the predictable hotel structure where everything becomes:

- giant hero image
- centered heading
- "Book now" button
- 3 identical room cards
- icon grid
- testimonials
- generic map
- footer

The required content sections may still exist, but their composition must feel custom.

Avoid:

- giant full-screen hero with only one slogan
- repetitive rectangular cards
- every section inside a rounded box
- excessive border-radius
- generic icon + title + text feature grids
- overuse of pills
- floating glassmorphism navigation
- huge gradients
- glowing effects
- neon colors
- generic stock-luxury hotel styling
- gold-on-black "premium hotel" clichés
- marble textures everywhere
- fake luxury language
- excessive serif typography
- alternating image-left / text-right sections repeated several times
- generic review sliders unless truly needed

Use composition, typography, photography and whitespace instead of endless containers.

Do NOT use:
- heavy ornamental patterns
- fake old-Russian typography
- excessive domes
- red-gold decorative motifs
- souvenir-shop aesthetics
- matryoshka / folklore clichés

Instead derive inspiration from local architectural character:

- old facades
- window proportions
- arches
- plaster textures
- historic brick
- narrow streets
- roof lines
- muted historic colors
- gates
- courtyards
- old signage
- architectural symmetry

These influences can appear through:

- image crops
- section proportions
- borders
- typography rhythm

- framing devices

The influence should be felt rather than literally illustrated everywhere.

# Booking Flow

There is no backend booking system yet.

Primary CTA:
- phone number
- WhatsApp message

The booking section may include:

- preferred dates
- number of guests
- room choice
- guest name

But the final action should lead to a WhatsApp conversation rather than pretending to complete a real reservation.

Do NOT create a fake "payment successful" or fake reservation flow.

If JavaScript is used, the form may generate a WhatsApp message with the selected details.

Example meaning:

"Здравствуйте! Хочу уточнить бронирование в «Тихой Коломне»: 12–14 сентября, 2 гостя, номер Комфорт."

Use placeholder phone data if no real number exists and make it easy to replace later.

The booking CTA should be obvious without being visually aggressive.

- long loading intros

# Before Coding

Before implementation:

1. Inspect the existing project.
2. Understand the current HTML, CSS and JavaScript.
3. Identify reusable content or functionality.
4. Choose one coherent design direction.
5. Define the visual system before styling every section independently.
6. Decide how architecture and local atmosphere influence the composition.
7. Then implement.

Do not accumulate unrelated design tricks.

---

# During Implementation

Continuously ask:

- Does this look like a generic hotel template?
- Does this feel like Booking or Airbnb?
- Does this look like an AI-generated landing page?
- Are there too many cards?
- Are there too many rounded rectangles?
- Is the local identity actually visible?
- Are room prices easy to understand?
- Can a visitor find the booking action quickly?
- Does the design feel calm rather than empty?
- Does it feel modern without becoming corporate?

If a section feels generic, redesign it.

---

# Final Quality Bar

The final site should feel believable enough that a visitor could think:

> "This guest house hired someone to design a site specifically for them."

It should NOT feel like:

> "A generic hotel template was filled with photos of Kolomna."

Prioritize:

1. distinctive boutique identity
2. clear room and price information
3. strong photography
4. local atmosphere
5. easy booking
6. responsive design
7. clean implementation
8. restrained, thoughtful motion

Do not stop at the first acceptable result.

If an idea feels generic, iterate.
